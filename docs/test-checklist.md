# 테스트 체크리스트

| 번호 | 테스트 항목 | 예상 결과 |
|---:|---|---|
| 1 | 정상 회원가입 | 계정이 생성되고 로그인 페이지로 이동 |
| 2 | 중복 아이디 회원가입 | 생성 거부 및 오류 메시지 |
| 3 | 비밀번호 해시 확인 | DB에 원문이 아닌 해시 저장 |
| 4 | 잘못된 비밀번호 로그인 | 공통 오류 메시지 |
| 5 | 비로그인 상품 등록 | 로그인 페이지로 이동 |
| 6 | 판매자의 상품 수정 | 정상 수정 |
| 7 | 다른 사용자의 상품 수정 | HTTP 403 |
| 8 | 다른 사용자의 상품 삭제 | HTTP 403 |
| 9 | 자신의 상품 구매 요청 | 요청 거부 |
| 10 | 중복 구매 요청 | 요청 거부 |
| 11 | 판매 완료 상품 구매 요청 | 요청 거부 |
| 12 | 구매자의 요청 승인 시도 | HTTP 403 |
| 13 | 판매자의 요청 승인 | 상품 SOLD, 선택 요청 ACCEPTED |
| 14 | 승인되지 않은 다른 요청 | 자동 REJECTED |
| 15 | XSS 문자열 출력 | HTML 이스케이프 |
| 16 | CSRF 토큰 없는 POST | HTTP 400 |
| 17 | 음수 가격 입력 | 검증 실패 |
| 18 | 긴 상품 설명 입력 | 검증 실패 |
